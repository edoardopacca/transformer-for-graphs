\section{Model}

We use a \emph{Graph Connectivity Transformer} trained to predict the full connectivity matrix of an input graph.

Given an undirected graph with \(n\) nodes (the value of \(n\) varies across experiments and is specified 
in each section), the input is its adjacency matrix with self-loops added:
\[
A \in \{0,1\}^{n \times n}.
\]
The target is the connectivity matrix:
\[
R \in \{0,1\}^{n \times n},
\]
where
\[
R_{ij} = 1
\quad \text{iff} \quad
i \text{ and } j \text{ belong to the same connected component.}
\]

Unless otherwise stated, the model configuration used in all experiments is:
\begin{itemize}
    \item Number of layers: \(2\)
    \item Number of attention heads: \(1\)
    \item Model dimension: \(d_{\mathrm{model}} = 64\)
    \item Feed-forward dimension: \(d_{\mathrm{ff}} = 128\)
    \item Dropout: \(0.0\)
    \item Batch size: \(256\)
    \item Optimizer: AdamW
    \item Learning rate: \(10^{-3}\)
    \item Weight decay: \(0.01\)
    \item Gradient clipping norm: \(1.0\)
    \item Training steps: \(500{,}000\)
    \item Evaluation frequency: every \(1000\) steps
\end{itemize}

The model is trained on fixed:
\begin{enumerate}
    \item Erd\H{o}s--R\'enyi datasets, with \(n = 10\) and with two values of edge probability:
\[
p \in \{0.2,\ 0.5\}.
\]
    \item 2-chains datasets, with \(n = 14\).
    \item 2-cliques datasets, with \(n = 14\).
    \item Erd\H{o}s--R\'enyi datasets with \(n = 40\), \(p = 0.05\), under four different tra
    ining-set diameter constraints (Section~\ref{sec:n40}).
\end{enumerate}
For each dataset (except where noted):
\begin{itemize}
    \item Training set size: \(6{,}000{,}000\) graphs
    \item Test set size: \(10{,}000\) graphs
\end{itemize}

The evaluation tracks:
\begin{itemize}
    \item \textbf{Exact Match Accuracy}: percentage of predicted \(n \times n\) connectivity matrices that are perfectly correct.
    \item \textbf{Pairwise Accuracy}: average correctness over all matrix entries.
    \item \textbf{Pairwise Accuracy by Distance}: accuracy conditioned on shortest-path distance in the test set.
    \item \textbf{Training Loss}: binary cross-entropy loss during optimization.
\end{itemize}

\subsection{Comments}

The experiments show that the model performs very well on in-distribution Erd\H{o}s--R\'enyi graphs. 
Both exact match accuracy and pairwise accuracy become extremely high very early during training, and the loss rapidly 
decreases toward zero.

However, the model is learning an effective \emph{heuristic} for the Erd\H{o}s--R\'enyi distribution rather than a fully 
robust algorithmic solution for graph connectivity.

This interpretation is supported by two observations:
\begin{itemize}
    \item The training loss, although very small, still exhibits slight oscillatory behavior instead of converging in a perfectly 
    stable way.
    \item Accuracy deteriorates as the shortest-path distance between node pairs increases. The degradation is limited for 
    common distances, but it becomes more visible for larger distances, where the number of test examples is also much smaller.
\end{itemize}

Therefore, the empirical picture is the following: on ER graphs the transformer appears to solve the task very well, 
but this may happen because the data distribution allows the model to exploit shortcuts or regularities.

The model achieves near-perfect performance on TwoChains, but this is likely due to the extreme regularity of the 
dataset rather than true algorithmic understanding.

\subsection{Periodic spikes in the training loss}

The training loss curve for the TwoChains experiment shows periodic spikes in
the Binary Cross-Entropy loss. These spikes have magnitude approximately
\(0.01\)--\(0.015\), and appear roughly every \(25{,}000\)--\(30{,}000\)
training steps over the full \(500{,}000\)-step training run.
The period of the spikes is consistent with the epoch length. Indeed, one epoch
corresponds to
\[
T_{\mathrm{epoch}}
=
\frac{N_{\mathrm{train}}}{\text{batch size}}
=
\frac{6{,}000{,}000}{256}
\approx 23{,}438
\]
training steps.

At the end of each epoch, the code samples a new random permutation of the
dataset indices. Therefore, the
examples are the same across epochs, but their order changes at every
epoch.
This interacts with the internal state of AdamW that keeps estimates of the first and second moments of
the gradients. These estimates depend on the
recent sequence of minibatches. When the order of the dataset changes at an
epoch boundary, the local sequence of gradients also changes. However, the
optimizer state is still calibrated to the previous sequence of minibatches.
This temporary mismatch produce a short transient increase in the loss.
After a few hundred steps, the optimizer state adapts to the new local gradient
statistics, and the loss returns to its previous level.

The observed period is slightly larger than the nominal epoch length because
the plotted training loss is smoothed over the last \(1{,}000\) steps.

\subsection{Out-of-distribution evaluation}

We complement the in-distribution evaluation by testing the same model trained on TwoChains on a completely 
different distribution: Erd\H{o}s--R\'enyi graphs with the same number of nodes \(n = 14\), at three edge 
probabilities \(p \in \{0.05,\, 0.2,\, 0.5\}\). Each test set contains \(10{,}000\) graphs.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{runs/ood_cross_experiment/ood_2chains_per_distance_bars.png}
    \caption{TwoChains (n = 14) model evaluated OOD on ER(n = 14), with different p. Each panel reports pairwise

The TwoChains model collapses out of distribution: \textbf{exact-match accuracy} is essentially \textbf{\(0\)} at all three edge densities,

The per-distance breakdown shows that accuracy is relatively higher at short distances (\(d = 1, 2\), where adjacency-like 
patterns are still present in ER graphs) and steadily decreases for larger distances. The largest source of error is the 
``disconnected'' bin.

\subsection{Comments}

The 2-cliques family with \(n = 14\) and \(k = 7\) is a structurally trivial dataset: the only degree of 
freedom is the partition of the 14 nodes into the two cliques. The number of distinct graphs in this family 
is therefore very small (\(\binom{14}{7}/2 = 1716\)), so we use the exhaustive set of partitions split into 
80\% training and 20\% test, and we cap the optimisation at 800 steps with evaluation every 10 steps.

In-distribution testing on this dataset is therefore not informative: the model reaches \(100\%\) exact match 
within a few hundred steps and stays there. With so few distinct graphs, the model can essentially memorise 
the training partitions, and the high accuracy is not evidence that it has learned a connectivity algorithm.

\subsection{Out-of-distribution evaluation}

As with the TwoChains model, we evaluate the trained TwoCliques checkpoint on ER\((n = 14, p)\) test sets with 
\(p \in \{0.05,\, 0.2,\, 0.5\}\), each containing \(10{,}000\) graphs.

\[

\]

\section{Diameter-controlled training on ER graphs (\(n = 40\))}
\label{sec:n40}

\subsection{Motivation}

The previous in-distribution experiments on ER graphs with \(n = 10\) suggest that the transformer is exploiting 
heuristics. With \(n = 10\) the maximum possible distance is small and most node pairs are very close, so local 
rules (e.g.\ ``two nodes that share a neighbour are reachable'') are sufficient to obtain near-perfect accuracy.

Following the paper on Disentangled Transformers, we ran additional experiments by restricting the training graphs 
to diameter \(<7\), \(<9\), and \(<11\), in order to test how diameter-based data selection affects learning. For 
our 2-layer model this gives \(3^2 = 9\) as the relevant capacity threshold. We therefore compare four training 
distributions with the same generative process, ER\((n=40,\, p=0.05)\), but different diameter filters \(D \le D^\star\) 
applied via rejection sampling at training time.

The choice \(n = 40\), \(p = 0.05\) (corresponding to expected degree \(d = np = 2\)) was made so that the three diameter 
cutoffs of interest (\(D \le 7\), \(D \le 9\), \(D \le 11\)) are all statistically meaningful: at this scale they accept 
respectively about \(14\%\), \(55\%\) and \(84\%\) of randomly generated graphs, producing genuinely different training 
distributions. With smaller \(n\) (e.g.\ \(n = 20\)) all three constraints accept more than \(95\%\) of graphs and the 
comparison becomes degenerate.

\subsection{Experimental setup}

We run four parallel experiments with identical model and optimiser configurations (the standard configuration listed 
in Section~1). The only varying factor is the training-set diameter filter:

\begin{itemize}
    \item \textbf{Unfiltered}: training graphs are sampled directly from ER\((40, 0.05)\).
    \item \textbf{D \(\le 11\)}: training graphs are sampled from ER\((40, 0.05)\) and rejected unless their maximum 
    finite shortest-path distance is at most 11.
    \item \textbf{D \(\le 9\)}: same procedure with cutoff 9.
    \item \textbf{D \(\le 7\)}: same procedure with cutoff 7.
\end{itemize}

For each experiment, the training set contains \(6{,}000{,}000\) graphs and the test set contains \(10{,}000\) graphs 
sampled from the same distribution as the training graphs (i.e.\ subject to the same diameter filter). All models are 
trained for \(500{,}000\) steps. Model checkpointing, evaluation cadence and optimiser hyperparameters are identical 
across the four runs.

Two observations follow directly from Figure~\ref{fig:n40-convergence}:

\paragraph{Convergence speed is monotone in the diameter filter.} Tighter constraints lead to faster learning, with a roughly 
seventeen-fold gap between the most restrictive (\(D \le 7\)) and the unfiltered training distribution. This is consistent 
with the intuition that filtering the training set towards graphs that the architecture can in principle solve produces a 
cleaner gradient signal at every step.

\paragraph{Final accuracy is essentially unaffected.} All four runs plateau in a narrow band around \(80\%\) exact match 
and \(99\%\) pairwise accuracy. The differences between the four final values are small (\(\sim 2\%\) in exact match) and 
well within the typical step-to-step variation of the metric in the last \(50{,}000\) steps. With \(n = 40\) each test graph 
contains \(40 \times 39 = 1{,}560\) off-diagonal pairs to predict, so a pairwise accuracy of \(0.99\) corresponds on average 
to about \(15\) wrong pairs per graph, which is enough to drive the exact-match metric down. The plateau at roughly \(0.80\) 
exact match across all four runs therefore strongly suggests that the bottleneck is the model capacity 
(\(d_{\mathrm{model}} = 64\), one head, two layers) rather than the difficulty of the training data.

\subsection{Results: accuracy as a function of node-pair distance}

A more diagnostic view is obtained by breaking down the final pairwise accuracy by shortest-path distance \(d\) 
between the two nodes. Figure~\ref{fig:n40-perdistance} shows this breakdown for the four trained models.

\begin{figure}[H]
    \centering
    \includegraphics[width=\textwidth]{runs/n40_cross_experiment/02_per_distance.png}
    \caption{Final pairwise accuracy broken down by shortest-path distance \(d\) for the four diameter-controlled 
    experiments. Background shading indicates the support of each filtered training distribution. Each curve is 
    truncated at the maximum \(d\) present in the corresponding test set.}
    \label{fig:n40-perdistance}
\end{figure}

Three patterns emerge from Figure~\ref{fig:n40-perdistance}.

\paragraph{Accuracy is near-perfect at small distances.} For \(d \le 5\) all four models predict pairs correctly 
with probability greater than \(0.995\), and within this range there is no meaningful difference among the four training filters.

\paragraph{Restrictive training is worse at the boundary.} At the boundary \(d = 7\), the ranking of the four 
models is \textit{inverted} with respect to what one might expect: the unfiltered model attains \(0.985\), 
the \(D \le 11\) model \(0.979\), the \(D \le 9\) model \(0.957\), and the \(D \le 7\) model only \(0.941\). 
In other words, the model that has been trained exclusively on graphs with \(D \le 7\) is the worst at predicting 
pairs at exactly \(d = 7\). A natural interpretation is that the more permissive training distributions provide 
the model with longer-range supervision, which helps disambiguate the boundary cases.

\paragraph{The unfiltered model collapses on long-range pairs.} Beyond \(d = 11\), only the unfiltered model 
has data to evaluate, and its accuracy decays sharply: \(0.83\) at \(d = 13\), \(0.45\) at \(d = 19\), \(0\) at \(d = 21\). 
These distances correspond to a small but non-negligible fraction of the test set ($\sim$15\% of graphs have diameter \(> 11\)) 
and account for most of the gap between the unfiltered model's exact-match accuracy and that of the diameter-restricted runs.

\subsection{Comments}

Putting the convergence and per-distance analyses together, we draw three main conclusions.

First, restricting the training distribution to graphs of diameter \(D \le D^\star\) dramatically accelerates learning, 
with a roughly seventeen-fold reduction in the number of steps required to reach \(99\%\) pairwise accuracy when going 
from unfiltered to \(D \le 7\). This is consistent with the picture proposed by recent work on disentangled transformers, 
in which an \(L\)-layer model is expected to learn most efficiently on graphs whose diameter does not exceed \(3^L\).

Second, despite this large gap in training efficiency, the four models plateau at essentially the same final exact-match 
accuracy of about \(0.80\). Combined with the observation that pairwise accuracy is consistently around \(0.99\) at the 
end of training, this strongly indicates that the bottleneck of the present setup is the size of the model rather than 
the structure of the training data. Future experiments aimed at validating or refuting the \(3^L\) prediction more 
rigorously should therefore include a sweep over \(d_{\mathrm{model}}\), \(n_{\mathrm{heads}}\) and \(n_{\mathrm{layers}}\).

Third, the per-distance analysis reveals that the diameter filter is not strictly beneficial. Models trained on more 
restrictive distributions are systematically worse at the boundary distances of those distributions, and the \(D \le 9\) 
model in particular (the configuration that exactly matches the \(3^L = 9\) prediction for our 2-layer architecture) 
underperforms both \(D \le 7\) and \(D \le 11\) on its own diameter range. This suggests that the relationship between 
training-set diameter and learned solution is not monotone, and that the empirical optimum may lie either below or above 
the theoretical \(3^L\) threshold depending on the metric of interest.

\subsection{Out-of-distribution: cross-experiment analysis}

The four diameter-controlled models reach similar in-distribution accuracy but differ substantially when evaluated outside 
the regime they were trained on. We probe this in three ways:
\begin{enumerate}
    \item evaluation on 2-chains graphs with random \(n_{\text{active}} \in \{14, 16, \ldots, 40\}\), padded to \(40 \times 40\) 
    with isolated nodes;
    \item evaluation on 2-cliques graphs with the same \(n_{\text{active}}\) protocol;
    \item evaluation on unfiltered ER\((n=40,\, p=0.05)\), with a per-graph-diameter breakdown of exact-match accuracy. For 
    the unfiltered model this coincides with the in-distribution evaluation and is reported for direct comparison; for the 
    diameter-restricted models the bucket D \(> 11\) is genuinely out of distribution because such graphs were rejected 
    during training.
\end{enumerate}
Each test set contains \(10{,}000\) graphs.

\subsubsection*{Behaviour on 2-chains}

\begin{figure}[H]
    \centering
    \includegraphics[width=0.95\textwidth]{runs/ood_cross_experiment/ood_cross_chains_per_distance.png}
    \caption{OOD evaluation on 2-chains: pairwise accuracy as a function of the chain-internal distance \(d\), compared 
    across the four diameter-controlled models. Each curve is averaged over all \(n_{\text{active}}\) values.}
    \label{fig:ood-chains-perdist}
\end{figure}

Across all four models the exact-match accuracy on 2-chains is \(0\), meaning that no test graph is predicted perfectly. 
The pairwise accuracy is in the range \(0.87\)--\(0.90\), but most of this signal comes from the (very many) padded-isolated 
pairs that are trivially disconnected. Restricting the comparison to the \(\sim 3.7\) million chain-internal reachable pairs 
gives a much cleaner picture:
\begin{itemize}
    \item Unfiltered: \(0.636\)
    \item D \(\le 9\): \(0.597\)
    \item D \(\le 7\): \(0.577\)
    \item D \(\le 11\): \(0.526\)
\end{itemize}
The unfiltered model is the best at transferring to chain structures, despite never having been trained on a chain graph. 
Figure~\ref{fig:ood-chains-perdist} makes the mechanism explicit: all four models are perfect at \(d \le 2\), virtually 
perfect at \(d = 3\)--\(4\), and then degrade. The unfiltered curve degrades the most slowly and is the only one that 
remains non-zero up to \(d = 15\). The diameter-restricted models drop to zero accuracy at, or even before, their 
respective training cutoffs (e.g.\ the D \(\le 7\) model is essentially zero from \(d = 7\) onward). The non-monotone 
behaviour of the D \(\le 11\) model is again visible: it underperforms even the D \(\le 9\) and D \(\le 7\) models in 
the \(d = 5\)--\(6\) range.

\subsubsection*{Behaviour on 2-cliques}

On the 2-cliques test set, three of the four models achieve exact-match accuracy of exactly \(0\). The only exception 
is the D \(\le 7\) model, which scores \(0.068\) overall: this number is entirely produced by the \(n_{\text{active}} = 14\) 
subset (where the model achieves \(100\%\) exact match), and is \(0\) for every other \(n_{\text{active}}\). Conditional on 
\(n_{\text{active}} = 14\) the input is a TwoCliques graph of two 7-cliques padded with \(26\) isolated nodes, whose overall 
diameter is \(1\) and whose structure is well within the D \(\le 7\) training distribution. As \(n_{\text{active}}\) grows 
the cliques become denser and the model fails entirely.

The per-distance breakdown is, for all four models, the same as in the TwoCliques-on-ER experiment of Section~4: \(d = 1\) 
accuracy is very low (\(\leq 0.08\)) and the disconnected category is the only one with consistently high accuracy. 
In other words, the n=40 ER-trained models read the very dense within-clique adjacency block as if it were noise, and 
predict disconnection for it. This is the mirror image of the TwoCliques-on-ER finding: where a model trained on cliques 
predicted ``edge implies same component'', the models trained on (sparse) ER data predict ``unusual edge density implies 
nothing about connectivity''.

Second, the more restrictive the training filter, the more catastrophic the failure on the bucket that was excluded 
from training. The D \(\le 7\) model achieves \(0.003\) exact match on D \(> 11\): out of \(1{,}452\) test graphs of 
high diameter, it gets four right. The D \(\le 9\) model reaches \(0.107\), and the D \(\le 11\) model reaches \(0.329\). 
The unfiltered model, which trained on this regime, reaches \(0.687\). The cost of a tight diameter filter is not a graceful 
degradation but a near-complete collapse on the rare and harder graphs.

Third, even on buckets that are nominally within the training distribution of all four models (e.g.\ D \(\le 7\) and D 
\(\le 9\)), the unfiltered model is competitive with or better than the corresponding specialist. The unfiltered model 
scores \(0.820\) on D \(\le 9\), versus \(0.792\) of the D \(\le 9\) specialist; on D \(\le 7\) the gap is small in the 
other direction (\(0.734\) vs \(0.803\) of the D \(\le 7\) specialist) but the unfiltered model loses \(7\) percentage 
points of accuracy on D \(\le 7\) graphs in exchange for being \(0.68\) accurate on D \(> 11\) graphs (where the D \(\le 7\) 
model is at \(0.003\)). The trade-off is not symmetric: diversity in training data buys back high-diameter generalisation at 
little cost on easy cases.

\subsubsection*{Comments}

Putting the three OOD experiments together with the in-distribution findings of Sections~5.2--5.6, we draw four conclusions.

First, all the in-distribution successes documented in Sections~2--4 fail to transfer. The TwoChains and TwoCliques models, 
which reach near-perfect in-distribution accuracy, score below the trivial constant baseline when tested on Erd\H{o}s--R\'enyi 
graphs of the same size. The four diameter-controlled ER models, which all reach roughly \(0.80\) exact match in distribution, 
achieve exact-match accuracy of \(0\) on both 2-chains and 2-cliques. There is no evidence in our experiments that the architecture
 is learning a general connectivity algorithm; the in-distribution performance is consistent with the learning of 
 distribution-specific shortcuts.

Second, the unfiltered model is the most robust under distribution shift, and is competitive with each diameter-restricted 
specialist on the latter's preferred regime. This contradicts a naive reading of the paper that motivates the 
diameter-controlled training: in our setting, filtering the training data to a narrow diameter range accelerates 
training (Section~5.3) but does not improve in-distribution accuracy (Section~5.3) and damages OOD performance 
(Table~\ref{tab:ood-er-buckets}).

Third, the diameter filter has a clearly asymmetric effect. A model trained on D \(\le D^\star\) loses very little
 accuracy on graphs with diameter \(\le D^\star\) when compared to the unfiltered baseline, but loses most of its 
 accuracy on graphs with diameter just above \(D^\star\) and almost all of it on graphs with diameter substantially 
 above \(D^\star\). The D \(\le 7\) model going from \(0.803\) on D \(\le 7\) to \(0.003\) on D \(> 11\) is the most 
 striking instance of this asymmetry.

Fourth, the \(D \le 9\) configuration (the one matching the \(3^L = 9\) prediction of the disentangled-transformer 
literature for our two-layer architecture) is not, by any of our metrics, an empirical optimum. On 2-chains it is 
beaten by the unfiltered model; on unfiltered ER it is beaten by the D \(\le 11\) model on the D \(\le 11\) and D
 \(> 11\) buckets and by the unfiltered model overall; and on its own D \(\le 9\) bucket it is beaten by both D 
 \(\le 11\) and unfiltered. The most defensible practical recommendation from this body of evidence is therefore 
 the simplest one: train on the broadest available distribution, accept the slower convergence, and obtain a model 
 that degrades more gracefully outside the training regime.
